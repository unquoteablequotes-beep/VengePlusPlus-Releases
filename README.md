# Venge++

A desktop client for Venge.io, available on Windows, Linux and macOS.

**[Download the latest release](https://github.com/unquoteablequotes-beep/VengePlusPlus-Releases/releases/latest)**

## Built for your game

- Refined lobby, in-game HUD and match results.
- Custom weapon and character cosmetics, charms and mastery progression.
- Halloween 2026 maps, event crate and rotating shop offers.
- Battle pass, daily quests and nuke tracking.
- Friends, group chat, clans and player badges.
- Settings import/export, custom crosshairs and mod management.

## Choose your download

| System | Package |
| --- | --- |
| Windows x64 | Setup installer or portable executable |
| Linux x64 | AppImage or Debian/Ubuntu package |
| macOS Apple Silicon | arm64 DMG or ZIP |
| macOS Intel | x64 DMG or ZIP |

**Windows:** Launch the installer or the portable executable. No separate game client is required.

**Linux:** Mark the AppImage executable before launching. If FUSE is unavailable, launch with `--appimage-extract-and-run`, or use the `.deb` package.

**macOS:** Choose the build matching your processor and move the app to Applications. The app is ad-hoc signed and is not Apple notarized; macOS may require **Privacy & Security → Open Anyway** after the first launch attempt.

Checksums are included with every release in `SHA256SUMS.txt`. Existing client settings are retained when upgrading. Windows builds currently use an unsigned publisher identity.
